# Sources

One source per line in the format `- <name> | <feed URL>`. The script `~/scripts/fetch_feeds.py` reads only these lines.
Supported: RSS, Atom and the JSON API of the Hugging Face Daily Papers.

- AlphaSignal | https://alphasignal.ai/feed.xml
- Import AI | https://importai.substack.com/feed
- Phil Schmid | https://www.philschmid.de/rss
- HF Trending Papers | https://huggingface.co/api/daily_papers
